# โครงสร้างโปรเจกต์และไฟล์ของระบบ CostFlow

คำอธิบายโฟลเดอร์และไฟล์หลักในระบบแบบแผนผังต้นไม้ สั้นๆ กระชับ เข้าใจง่าย:

```text
CostFlow/
├── Controllers/            # โฟลเดอร์ควบคุมการทำงานแต่ละหน้าจอ (รับค่าจากเว็บ -> สั่งงาน -> ส่งผลลัพธ์กลับ)
│   ├── AccountController.cs       # จัดการระบบล็อกอิน และออกจากระบบ
│   ├── FileMergeController.cs     # จัดการอัปโหลดไฟล์แผนผลิตและใบขออนุมัติ เพื่อเปรียบเทียบราคา
│   ├── ProductSearchController.cs # จัดการค้นหาอะไหล่อัตโนมัติ และบันทึกใบสั่งซื้อสะสม
│   ├── PriceReferenceController.cs# จัดการตารางราคากลางอะไหล่อ้างอิง (เพิ่ม/ลบ/แก้ไข)
│   └── ReportController.cs        # จัดการดูรายงานผลต่างราคา และดาวน์โหลดไฟล์ Excel
│
├── Models/                 # โฟลเดอร์เก็บโครงสร้างตารางฐานข้อมูลในระบบ
│   ├── DbEntities.cs              # ตารางหลัก เช่น ข้อมูลสินค้า, ใบสั่งซื้อ, ประวัติเปรียบเทียบไฟล์
│   └── ApplicationUser.cs         # ตารางข้อมูลผู้ใช้ ขยายเพิ่มรหัสพนักงานและชื่อ-นามสกุล
│
├── ViewModels/             # โฟลเดอร์เก็บโครงสร้างข้อมูลชั่วคราว สำหรับส่งไปแสดงผลบนหน้าเว็บ
│   └── FileMergeViewModel.cs      # เก็บข้อมูลผลลัพธ์เปรียบเทียบไฟล์ เพื่อแสดงบนตารางหน้าเว็บ
│
├── Services/               # โฟลเดอร์เก็บโค้ดทำงานเบื้องหลัง (ระบบคำนวณและประมวลผลไฟล์)
│   ├── ImportDbService.cs         # ระบบอ่านไฟล์ Excel/CSV และจับคู่คำนวณส่วนต่างราคา
│   ├── ExportService.cs           # ระบบสร้างไฟล์สรุปผล Excel สำหรับดาวน์โหลด
│   └── CustomUserClaimsPrincipalFactory.cs # ระบบเก็บข้อมูลชื่อและสิทธิ์ลง Cookie เพื่อลดการดึงข้อมูลจาก DB
│
├── Data/                   # โฟลเดอร์ตั้งค่าการเชื่อมต่อฐานข้อมูล
│   └── AppDbContext.cs            # ไฟล์เชื่อมต่อและตั้งค่าตารางฐานข้อมูล MySQL
│
├── Views/                  # โฟลเดอร์เก็บหน้าเว็บอินเตอร์เฟส (.cshtml)
│   ├── Shared/                    # หน้าเว็บส่วนกลาง เช่น เมนูบาร์ด้านซ้าย (_Layout.cshtml)
│   ├── Account/                   # หน้าล็อกอินเข้าสู่ระบบ
│   ├── FileMerge/                 # หน้าอัปโหลดและแสดงตารางเปรียบเทียบไฟล์
│   ├── ProductSearch/             # หน้าฟอร์มบันทึกใบสั่งซื้ออะไหล่สะสม
│   ├── PriceReference/            # หน้าจัดการตารางราคากลางอะไหล่
│   └── Report/                    # หน้าดูประวัติรายงานผลต่างราคา
│
├── wwwroot/                # โฟลเดอร์เก็บไฟล์ตกแต่งเว็บ (รูปภาพ, CSS, JavaScript)
│   ├── css/                       # tailwind.min.css และ site.css
│   ├── js/                        # JavaScript สำหรับการทำงานเสริมหน้าเว็บ
│   └── data/                      # ไฟล์ข้อมูลเริ่มต้นสำหรับระบบ
│
├── docs/                   # โฟลเดอร์เก็บไฟล์คู่มืออธิบายการทำงานของระบบ
├── Dockerfile              # ไฟล์คำสั่งสำหรับนำเว็บขึ้นไปเปิดใช้งานบนเซิร์ฟเวอร์คลาวด์ (Render.com)
└── Program.cs              # ไฟล์เริ่มต้นการทำงานของระบบ ตั้งค่าฐานข้อมูลและระบบล็อกอิน
```
