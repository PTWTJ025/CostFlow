# ระบบรายงานและแผนผลิต (Report System)

## 📋 ภาพรวมระบบ

ระบบนี้ใช้สำหรับจัดการและติดตามใบสั่งผลิต (Order Tracking) โดยแบ่งการแสดงผลตามเดือน/ปี และจับคู่กับแผนผลิตสัปดาห์ (Weekly Plan)

---

## 🔄 Flow การทำงานหลัก

```
┌─────────────────────────────────────────────────────────────┐
│  1. หน้า Index (รายเดือน)                                   │
│     /Report                                                 │
│     - แสดงการ์ด 12 เดือน                                    │
│     - แต่ละการ์ดแสดงจำนวนและยอดรวมของเดือนนั้น              │
└─────────────────────────────────────────────────────────────┘
                           ↓ คลิกเดือน 5
┌─────────────────────────────────────────────────────────────┐
│  2. หน้า Details (รายละเอียดเดือน)                         │
│     /Report/Details?month=5&year=2026                       │
│     - แสดงรายการใบสั่งผลิตที่อนุมัติในเดือนนั้น             │
│     - สถานะ: Matched (มีแผน) / Pending (ยังไม่มีแผน)       │
│     - ปุ่ม "นำเข้าแผนผลิต" สำหรับอัปโหลดไฟล์ Excel         │
└─────────────────────────────────────────────────────────────┘
                           ↓ กด "ดูรายการทั้งหมด"
┌─────────────────────────────────────────────────────────────┐
│  3. หน้า AllOrders (รายการทั้งหมด)                         │
│     /Report/AllOrders?returnReportName=พฤษภาคม 2569        │
│                      &month=5&year=2026                     │
│     - แสดงรายการทั้งหมดในระบบ                              │
│     - ข้อมูลจากทั้ง OrderTrackingMasters และ Weekly Plans │
│     - สามารถกรองตามสถานะ (Matched/Pending/Unmatched)       │
└─────────────────────────────────────────────────────────────┘
```

### 3. หน้า AllOrders
```csharp
// API รับพารามิเตอร์ month และ year
public async Task<IActionResult> GetUploadedWeeklyPlanEntries(
    int? month, int? year)
{
    // 1. ดึงข้อมูลจาก OrderTrackingMasters

            .Where(o => ParseThaiDate(o.ApprovedDate).Month == month)

        unmatchedDetails = unmatchedDetails
            .Where(d => ParseThaiDate(d.DeliveryTarget).Month == month)
    }
}
```

## 📊 การแสดงข้อมูลใน AllOrders

### แหล่งข้อมูล 2 แหล่ง:

1. **OrderTrackingMasters** (ใบสั่งผลิต)
   - กรองตาม: `ApprovedDate` = เดือน/ปีที่เลือก
   - สถานะ: `Matched` หรือ `Pending`
   - แสดง: เลขที่อนุมัติ, วันที่อนุมัติ, ราคา, สถานะ

2. **WeeklyPlanDetails** (แผนผลิตสัปดาห์ที่ไม่ match)
   - กรองตาม: `DeliveryTarget` = เดือน/ปีที่เลือก
   - สถานะ: `Unmatched`
   - แสดง: เลขที่ PO ในไฟล์, ชื่อรายการ, ไฟล์แผนผลิต

## 🎨 สถานะของรายการ

| สถานะ | ความหมาย | แหล่งข้อมูล |
|-------|----------|-------------|
| **Matched** | มีใบสั่งผลิต และมีแผนผลิตแล้ว | OrderTrackingMasters |
| **Pending** | มีใบสั่งผลิต แต่ยังไม่มีแผนผลิต | OrderTrackingMasters |
| **Unmatched** | มีในแผนผลิต แต่ไม่ตรงกับใบสั่งผลิต | WeeklyPlanDetails |

## 📝 ตัวอย่างการใช้งาน

### กรณีที่ 1: ยังไม่มีแผนผลิต
1. เข้า `/Report` → เลือกเดือน 5
2. เข้า `/Report/Details?month=5&year=2026`
3. เห็นรายการสถานะ **Pending** ทั้งหมด
4. กด "ดูรายการทั้งหมด"
5. ✅ จะเห็นรายการจาก OrderTrackingMasters

### กรณีที่ 2: มีแผนผลิตแล้ว
1. ในหน้า Details กด "นำเข้าแผนผลิต"
2. อัปโหลด Excel → ระบบจับคู่อัตโนมัติ
3. สถานะเปลี่ยนเป็น **Matched**
4. กด "ดูรายการทั้งหมด"
5. ✅ จะเห็นทั้ง Matched, Pending, และ Unmatched

## 🛠️ การแก้ไขที่ทำไปแล้ว

### ปัญหาเดิม
- ❌ AllOrders ดึงข้อมูลเฉพาะจาก WeeklyPlanDetails
- ❌ ถ้ายังไม่อัปโหลดแผนผลิต หน้า AllOrders จะว่างเปล่า
- ❌ ไม่มีการส่ง month/year ระหว่างหน้า

### การแก้ไข
1. **เพิ่มพารามิเตอร์ month/year**
   - Details action รับ `month` และ `year`
   - AllOrders action รับ `month` และ `year`
   - GetUploadedWeeklyPlanEntries API รับ `month` และ `year`

2. **ปรับ API GetUploadedWeeklyPlanEntries**
   - ดึงข้อมูลจาก **OrderTrackingMasters** (ใบสั่งผลิต)
   - ดึงข้อมูล Unmatched จาก **WeeklyPlanDetails**
   - Merge ข้อมูลทั้งสองแหล่ง

3. **ส่งพารามิเตอร์ระหว่างหน้า**
   - Details.cshtml ส่ง month/year ไปยัง AllOrders
   - AllOrders.cshtml ใช้ month/year ในการกรองและ breadcrumb

4. **แก้ปัญหา IAsyncQueryProvider**
   - เปลี่ยนจาก mixed EF/LINQ queries
   - เป็น fetch-all-then-filter-in-memory
