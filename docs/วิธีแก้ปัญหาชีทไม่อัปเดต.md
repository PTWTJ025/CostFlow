# 🔧 วิธีแก้ปัญหา Google Sheets ไม่อัปเดตข้อมูล

## 🚨 ปัญหาที่พบ
1. ข้อมูลบันทึกลง Database แล้ว แต่ไม่ขึ้น Google Sheets
2. เห็นชื่อเดือนแสดงเป็น "2025-122" แทนที่จะเป็น "ธันวาคม 2568"

## ✅ สาเหตุ
**Google Apps Script ยังคาดหวัง 10 columns แต่ระบบ C# ส่งมาแค่ 9 columns**

เราได้เปลี่ยนโครงสร้างคอลัมน์แล้ว:
- ❌ เดิม: 10 columns (มี "เคยผ่อนจาก" และ "ยกยอดมาจาก" แยกกัน)
- ✅ ใหม่: 9 columns (รวมเป็น "ยกยอดมาจาก" เพียงคอลัมน์เดียว)

## 📋 ขั้นตอนการแก้ไข

### 1️⃣ เปิดไฟล์ Script ที่เตรียมไว้ให้
เปิดไฟล์: `d:\ProjectIntern\CostFlow\docs\google-apps-script-9-columns.js`

### 2️⃣ คัดลอกโค้ดทั้งหมด
- กด **Ctrl+A** เพื่อเลือกทั้งหมด
- กด **Ctrl+C** เพื่อคัดลอก

### 3️⃣ เข้า Google Sheets และเปิด Apps Script Editor
1. เปิด Google Sheets ที่คุณใช้อยู่
2. ไปที่เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
3. จะเห็นโค้ดเก่าอยู่ในไฟล์ `Code.gs`

### 4️⃣ แทนที่โค้ดเก่าด้วยโค้ดใหม่
1. **ลบโค้ดเก่าทั้งหมด** ในไฟล์ `Code.gs`
2. **วางโค้ดใหม่** ที่คัดลอกมาจากไฟล์ `google-apps-script-9-columns.js`
3. กด **Ctrl+S** หรือคลิกไอคอน 💾 เพื่อบันทึก

### 5️⃣ Deploy ใหม่
1. คลิกปุ่ม **Deploy** (มุมบนขวา) → เลือก **Manage deployments**
2. คลิกไอคอน **⚙️ (เฟือง)** ที่ deployment เก่า
3. เลือก **Version: New version**
4. ใส่คำอธิบาย (ถ้าต้องการ): `"Update to 9 columns (remove เคยผ่อนจาก)"`
5. คลิก **Deploy**
6. **คัดลอก URL ใหม่** (หรือใช้ URL เดิมก็ได้ ถ้า URL ไม่เปลี่ยน)

### 6️⃣ ตรวจสอบ URL ใน appsettings.json
เปิดไฟล์ `appsettings.json` และตรวจสอบว่า:

```json
{
  "GoogleSheets": {
    "MonthlyCostAppScriptUrl": "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec"
  }
}
```

ถ้า URL เปลี่ยน ให้อัปเดต URL ใหม่

### 7️⃣ รีสตาร์ทแอปพลิเคชัน
```bash
# หยุดแอป (ถ้ากำลังทำงานอยู่)
# กด Ctrl+C ใน terminal

# Build และรันใหม่
dotnet build
dotnet run
```

## ❓ ถ้ายังไม่ขึ้นชีท ให้เช็คอะไร?

### 1. เช็ค Console Log
ดูใน Terminal ที่รันแอป ว่ามี error อะไรไหม:
```bash
# ถ้าเห็นแบบนี้ = สำเร็จ
[AutoClosePriorMonthsAsync] ✅ Successfully synced 1 month(s) to Google Sheets

# ถ้าเห็นแบบนี้ = ล้มเหลว (ดู error message)
[AutoClosePriorMonthsAsync] ❌ Failed to sync to Google Sheets: ...
```

### 2. เช็ค Google Apps Script Log
1. เปิด Apps Script Editor
2. ไปที่ **Executions** (ด้านซ้าย)
3. ดูว่ามี error อะไรไหม

### 3. เช็ค appsettings.json
ตรวจสอบว่า URL ถูกต้อง:
```json
{
  "GoogleSheets": {
    "MonthlyCostAppScriptUrl": "https://script.google.com/macros/s/YOUR_ACTUAL_DEPLOYMENT_ID/exec"
  }
}
```

URL ต้อง:
- ✅ ขึ้นต้นด้วย `https://script.google.com/macros/s/`
- ✅ ลงท้ายด้วย `/exec`
- ✅ **ไม่มี** `_placeholder` หรือ `YOUR_DEPLOYMENT_ID`

### 4. ลองทดสอบส่งข้อมูลแบบ Manual
กดปุ่ม **"บันทึกรายการ"** หลังเลือกสินค้า → ถ้าขึ้นชีท แปลว่า Script ใช้งานได้แล้ว
