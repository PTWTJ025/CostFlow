# 📋 สรุปการแก้ไขและขั้นตอนทดสอบ

## 🎯 ปัญหาที่แก้ไข

### 1. Google Sheets ไม่แสดงข้อมูล
- **สาเหตุ**: Google Apps Script ยังคาดหวัง 10 columns แต่ C# ส่งมาแค่ 9 columns
- **การแก้ไข**: สร้าง Google Apps Script ใหม่ที่รองรับ 9 columns
- **ไฟล์**: `docs/google-apps-script-9-columns.js`

### 2. Auto-Skip ไม่ส่งข้อมูลไปชีท
- **สาเหตุ**: Background Service ยังไม่ได้เรียก Sync method
- **การแก้ไข**: 
  - สร้าง `MonthlyOrderSyncService` เพื่อแชร์ logic ระหว่าง Controller และ Background Service
  - แก้ไข `AutoSkipBackgroundService` ให้เรียก service นี้
  - แก้ไข `MonthlyCostController` ให้ใช้ service แทนโค้ดซ้ำ

### 3. ชื่อเดือนแสดงเป็น "2025-122"
- **สาเหตุ**: Database มีข้อมูล MonthYear ที่เก็บผิด format (มากกว่า 7 ตัวอักษร)
- **การแก้ไข**: ผู้ใช้รัน SQL แล้ว: `UPDATE MonthlyOrderActions SET MonthYear = SUBSTR(MonthYear, 1, 7) WHERE LENGTH(MonthYear) > 7`
- **ผลลัพธ์**: แก้ไข 159 rows สำเร็จ ✅

## ✅ ขั้นตอนที่ต้องทำตอนนี้

### 🔴 ขั้นตอนที่ 1: อัปเดต Google Apps Script (สำคัญที่สุด!)

1. **เปิดไฟล์**: `d:\ProjectIntern\CostFlow\docs\google-apps-script-9-columns.js`
2. **คัดลอกโค้ดทั้งหมด** (Ctrl+A, Ctrl+C)
3. **เปิด Google Sheets** ที่คุณใช้อยู่
4. ไปที่ **Extensions** → **Apps Script**
5. **ลบโค้ดเก่าทั้งหมด** ในไฟล์ `Code.gs`
6. **วางโค้ดใหม่** ที่คัดลอกมา
7. **บันทึก** (Ctrl+S หรือคลิกไอคอน 💾)
8. **Deploy ใหม่**:
   - คลิก **Deploy** → **Manage deployments**
   - คลิกไอคอน **⚙️** ที่ deployment เก่า
   - เลือก **Version: New version**
   - ใส่คำอธิบาย: `"Update to 9 columns"`
   - คลิก **Deploy**
9. **คัดลอก URL** (ถ้า URL เปลี่ยน ต้องไปอัปเดตใน `appsettings.json`)

## 🔧 การแก้ปัญหา

### ❌ ถ้ายังไม่ขึ้นชีท

#### 1. เช็ค Console Log
ดูใน Terminal ที่รันแอป:

```bash
# ✅ สำเร็จ
[AutoClosePriorMonthsAsync] ✅ Successfully synced 1 month(s) to Google Sheets

# ❌ ล้มเหลว (ดู error message)
[AutoClosePriorMonthsAsync] ❌ Failed to sync to Google Sheets: ...
```

#### 2. เช็ค Google Apps Script Log
1. เปิด Apps Script Editor
2. ไปที่ **Executions** (ด้านซ้าย)
3. ดูว่ามี error อะไรไหม

#### 3. เช็ค appsettings.json
ตรวจสอบว่า URL ถูกต้อง:

```json
{
  "GoogleSheets": {
    "MonthlyCostAppScriptUrl": "https://script.google.com/macros/s/YOUR_ACTUAL_DEPLOYMENT_ID/exec"
  }
}
```

URL ต้อง:
- ✅ ขึ้นต้นด้วย `https://script.google.com/macros/s/`
- ✅ ลงท้ายด้วย `/exec`
- ✅ **ไม่มี** `_placeholder` หรือ `YOUR_DEPLOYMENT_ID`

#### 4. ทดสอบ Manual
กดปุ่ม **"บันทึกรายการ"** หลังเลือกสินค้า → ถ้าขึ้นชีท แปลว่า Script ใช้งานได้

